# flora_scan

Global Bio-Telemetry & AI Diagnostics Plant Care App.

## Getting Started

This project is a starting point for a Flutter application.

### Configuration

This app requires a Supabase backend. You must provide the Supabase URL and Anonymous Key at build time using `--dart-define`.

#### Running the App

To run the app, use the following command (replacing the placeholders with your actual Supabase credentials):

```bash
flutter run \
  --dart-define=SUPABASE_URL=https://your-project.supabase.co \
  --dart-define=SUPABASE_ANON_KEY=your-anon-key
```

**Note:** Do NOT commit your actual keys to version control.
